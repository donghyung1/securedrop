# A·B·C 역할별 남은 작업

기준일: 2026-10-19. `SecureDrop_Cloud_PRD_v1.3_3.txt`의 6장·10장·12장·13장을 현재 코드, 역할 문서, 기존 배포 검증 결과와 대조했다. 이번 점검에서는 AWS 조회·배포·실제 브라우저 테스트를 새로 실행하지 않았다.

상태는 **미구현**(필요한 코드·산출물이 없음), **보완**(기존 구현에 추가 작업 필요), **확인 필요**(구현은 있으나 완료 증거 부족), **선택**(필수 완료 대상 아님)으로 구분한다. 확인 필요 항목을 구현 미완료로 단정하지 않는다.

## 완료 항목으로 판단한 범위와 문서 정리

| 항목 | 판단 및 남은 정리 |
|---|---|
| 핵심 서버리스 전송 | 기존 `backend/deploy/aws/serverless-verification.json`은 9개 항목 통과 기록. 검사·정제 API, S3 직접 업로드, QR, 관리 토큰 일부, 폐기 후 객체 접근 차단, 플러그인 키, CORS, 웹 자산·보안 헤더 포함. 해당 기능을 신규 구현 할 일로 다시 잡지 않음 |
| 웹 기본 업로드·다운로드 | 기존 `browser-verification.json`은 정상·위험 확인·미지원 형식 업로드와 다운로드, 모바일 레이아웃 등 5개 항목 통과 기록. 정제 UI·실물 모바일·성능까지 확인한 것은 아님 |
| 관리자 화면·확장 기본 흐름 | `docs/B_ROLE.md`와 테스트 문서에 로그인·집계·확장 이벤트·강제 폐기·로그아웃 및 확장 기본 시연 확인 기록이 있으므로 신규 구현에서 제외 |
| 정제·플러그인·E2EE 진행 표시 | `frontend/README.md`에는 플러그인·E2EE가 미완료로 표시되지만 실제 구현 파일이 있음. `backend/README.md`의 새 웹 정제 미구현 문구도 현재 코드와 불일치. 담당 A·B·C가 구현/검증 상태를 나눠 갱신할 것 |
| 테스트 계약·발표 수치 | B가 `tests/test_cases.md`의 구버전 5MB 상한, `confirm_sensitive`, `/api/logs` 등의 표현을 v1.3 계약과 대조해 수정. 테스트 건수 56/69와 F-03 오탐을 포함한 발표 수치도 최신 결과에 맞출 것 |
| 관리자 API 경로 | 현재 코드는 관리자 API를 CloudFront의 `/api/admin/*` 경로로 프록시하지만 PRD 8.1은 API 프록시를 하지 않는다고 명시. A가 이 변경의 채택 여부와 이유를 PRD·런북에 반영하거나 경로를 명세에 맞출 것 |

선택 기능은 필수 작업과 별도로 판단한다. PRD의 일정 지연 시 제외 순서는 **E2EE(F12) → 다중 파일(F10) → 내 전송 목록(F11) → 플러그인(F4, Swagger 대체)**이다. 일반 사용자 로그인, PDF·Excel 내부 검사, 관리자 MFA 등 PRD 비목표는 남은 필수 작업에 포함하지 않았다.
